Descripción del proyecto

Sistema de gestión de turnos para centros de estética
Nuestro proyecto consiste en desarrollar un sistema de gestión de turnos para centros de estética, pensado para facilitar y organizar la reserva de tratamientos tanto para las clientas como para las profesionales y administradores del establecimiento.
Actualmente, la reserva de turnos en muchos centros de estética se realiza mediante WhatsApp, llamadas telefónicas o mensajes en redes sociales. Este método puede resultar práctico cuando hay pocos clientes, pero a medida que aumenta la cantidad de consultas se vuelve difícil de administrar. La profesional debe responder mensajes, revisar manualmente su disponibilidad, consultar qué tratamientos realiza cada esteticista y controlar que no se asignen dos turnos para el mismo horario o gabinete. Para la clienta, esto puede significar esperar una respuesta, intercambiar varios mensajes y no tener una visión clara de los horarios disponibles.
Nuestro sistema busca centralizar este proceso y hacerlo más simple. La clienta podrá ingresar a la aplicación, seleccionar el tratamiento que desea realizar, elegir una esteticista que esté capacitada para realizarlo, seleccionar una fecha y consultar los horarios disponibles. Una vez elegido el horario, podrá realizar la reserva y consultar posteriormente sus turnos.
Del lado del centro de estética, el sistema permitirá organizar la agenda de las profesionales, administrar los tratamientos y controlar la disponibilidad de los gabinetes. De esta manera, se busca reducir errores en la asignación de turnos y facilitar la gestión diaria del establecimiento.
El sistema aporta beneficios para todos los usuarios. Las clientas podrán reservar sus turnos de una manera más rápida y autónoma, sin depender de que alguien responda un mensaje. Las esteticistas podrán contar con una agenda organizada y conocer sus turnos de manera centralizada. Los administradores tendrán herramientas para gestionar profesionales, tratamientos, gabinetes y turnos, reduciendo tareas manuales y mejorando la organización del centro.
El público objetivo está compuesto principalmente por centros de estética y sus clientas. Dentro del sistema se contemplan tres tipos principales de usuarios: clientas, que realizan las reservas; profesionales o esteticistas, que brindan los tratamientos; y administradores, responsables de la gestión y configuración del sistema.
En definitiva, el proyecto propone transformar un proceso que actualmente puede depender de mensajes y coordinación manual en una herramienta digital que permita gestionar los turnos de manera organizada, sencilla y accesible para todos los involucrados.
